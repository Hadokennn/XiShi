# 夕拾 · Xishi

> 朝花夕拾——白天散落开的花，傍晚一一拾起。
>
> 一款 AI 驱动的手帐式"第二大脑"手机应用。
> 不是 chat agent，是会自己消化你乱扔进来的东西的**空间化手帐**。

## 这是什么

市面上的 chat agent 都是**线性流**——日抛或周抛，context 一断就没了。

手帐是**图层**：

- 一天 = 一页画布，按分区组织（灵感 / 亲子 / 心情 / …）
- 你白天随手扔（语音、文字、图片），晚上 AI 自动"装订"成手帐
- 每个分区是可深入的入口——点进去 AI 已经替你"开荒"过了：拓展、关联历史、追问反思
- 跨天的"第二大脑"沉淀：今天孩子又因为同样的事情发脾气 → AI 立刻调出 3 周前那条育儿记录

**核心差异：chat 是给你"问问题"的，手帐是给你"过日子"的。**
